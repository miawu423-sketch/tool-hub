时间戳就地转换

Bookmarklet + 网页版 + 扩展版

在任意网页上选中文本，自动识别其中的 Unix 时间戳（秒/毫秒）或常见日期格式，在选区旁弹出气泡显示 yyyy/MM/dd HH:mm:ss 格式的可读时间。支持格式切换、时区选择、一键复制。

✓ 四种时间戳格式 Unix 秒（10位）、毫秒（13位）、ISO 8601、yyyy-MM-dd HH:mm:ss
✓ 气泡就地展示 选中文字后选区旁自动弹气泡，不切页面，点击即复制
✓ 格式/时区可选 气泡内置下拉切换：5种显示格式 + 本地/UTC/±N 时区
✓ 双版本覆盖 Bookmarklet 版（零门槛）+ Chrome 扩展版（CSP 受限页面也可用）
⏱ 时间戳转换
← 按住按钮，拖到浏览器书签栏即可安装
⚠️ 直接点击按钮不会安装，必须拖拽到书签栏。如果书签栏没显示：Chrome/Edge ⌘+Shift+B，Safari「显示 → 个人收藏栏」。
使用方法
  1. 打开任意网页（日志系统、监控面板、聊天记录均可）
  2. 点击书签栏的「⏱ 时间戳转换」，页面右下角出现绿色提示表示已启用
  3. 鼠标划中一段含时间戳的文字（如 1721028573）
  4. 选区旁自动弹气泡，显示转换结果；点击时间可复制
  5. 再次点击书签 = 关闭；页面刷新后需重新点击启用
试试选中这段文字：created_at: 1721028573, updated: 1721028573123, since 2024-07-15T10:49:33Z

发布时间提取

v3 7层策略版

从网页源码中 7 层策略 依次提取文章发布时间，所有结果统一转换为北京时间。优先取 dateModified（更新时间），对于头条等推荐平台自动跳过不可靠的修改时间。最佳结果自动复制到剪贴板。

✓ 7 层提取策略 Meta 标签 → JSON-LD → Script 变量 → Time 标签 → Data 属性 → Class/ID 模式 → 正则正文
✓ 智能偏好更新时间 优先取 dateModified；头条/百度/网易等推荐平台自动识别并跳过不可靠的修改时间
✓ 统一北京时间 所有输出自动转北京时间，支持 ISO 8601 / 中文日期 / Unix 时间戳 / RFC 2822 等格式
✓ 远程自动更新 每次点击从 GitHub Pages 拉取最新 JS，策略优化无需重装书签
🕐 Publish Time
← 拖到书签栏即可安装。每次点击自动获取最新版本。
使用方法
  1. 打开目标网页：打开任意文章页面（新闻、博客、论文均可）
  2. 点击书签：点击书签栏中的「🕐 Publish Time」
  3. 查看结果：右侧弹出面板，7 层策略结果按精度从高到低排列
  4. 自动复制：最佳结果（绿色高亮）自动复制到剪贴板，直接粘贴使用
7 层提取策略详情
层级策略来源示例
1Meta 标签article:published_time, pubdate, dc.date.issued, sailthru.date 等 20+ 种
2JSON-LD 解析datePublished, dateModified, 递归查找 @graph/mainEntity
3Script 变量"created_at", "publishTime", "time" key, /Date(ms)/ 等
4Time 标签<time datetime="...">
5Data 属性data-publish-time, data-pubtime, data-timestamp 等
6Class/ID 模式包含 publish*time, post*time, date 等关键字的元素
7正则正文匹配「发布时间：」「发布于」「更新于」后跟日期时间
支持的格式：2024-07-15T10:49:33Z · 2024年7月15日 10:49 · 1721028573（Unix秒） · Sun, 09 Mar 2025 22:21:38 +0900 · /Date(1721028573000+0800)/

复制 href 原文

Bookmarklet

浏览器右键「复制链接地址」返回的是 URL 规范化后的结果（补斜杠、百分号转义、相对路径转绝对），不是 HTML 里的原始 href。这个工具读 getAttribute('href')，逐字节返回原文，绕过规范化。

✓ 逐字节原文 不补 /、不转义空格/中文、不解析相对路径，拿到 HTML 里写的原始值
✓ 点击即复制 激活后点任意链接，原始 href 直接进剪贴板，悬停有橙色高亮提示
✓ 复制全部 一键把整页链接按行导出，自动去重
✓ 不干扰浏览 激活期间点击不跳转，Esc 退出后恢复；再次点击书签即可关闭
⛓ 复制href原文
← 拖到书签栏即可安装，自动获取最新版本
使用方法
  1. 点击书签：点书签栏的「⛓ 复制href原文」，页面底部出现工具条
  2. 点任意链接：原始 href 进剪贴板（激活期间不会跳转）
  3. 复制全部：点工具条的「复制全部」，整页链接按行导出
  4. 退出：按 Esc 或点「退出」按钮
为什么需要它
HTML 原文右键复制得到规则
https://a.io?x=1https://a.io/?x=1空路径补斜杠 /
https://a.io/a bhttps://a.io/a%20b空格百分号编码
https://a.io/x?q=中文...?q=%E4%B8%AD%E6%96%87非 ASCII 编码
../page.htmlhttps://host/dir/page.html相对路径解析为绝对
💡 DevTools 元素面板显示的是属性原文，右键复制取的是 a.href（规范化后的 IDL 属性）——两者本就是不同值，不是系统 bug。

网页内容复制

浏览器扩展

一个 Chrome / Edge 浏览器扩展——在网页上框选任意区域，本地 Tesseract.js OCR 引擎自动识别文字并复制到剪贴板。无需截图、无需切换软件、无需网络，完全离线运行。

✓ 框选即复制 拖拽框选网页任意区域，松开后自动 OCR 识别并复制，一步到位
✓ 本地离线 OCR 使用本地 Tesseract.js（中英文），无需网络，数据不上传
✓ 三种触发方式 快捷键 Ctrl+Shift+O / 右键菜单 / 工具栏图标点击
✓ 识别后编辑 弹出可编辑浮层，支持去空格/去换行/去标点/半角转全角，撤销栈最多20步
📥 下载扩展
← 点击直接下载最新版 ZIP，每次都是 main 分支最新代码
安装方法
  1. 下载扩展：点击上方「📥 下载扩展」按钮，下载最新版 ZIP
  2. 解压文件：将 ZIP 解压，注意解压后有一个 web-ocr-copy-main 文件夹，把这个文件夹放到方便的位置
  3. 打开扩展页面：Chrome/Edge 地址栏输入 chrome://extensions
  4. 开启开发者模式：右上角打开「开发者模式」开关
  5. 加载扩展：点击「加载已解压的扩展程序」，选择 web-ocr-copy-main 文件夹（含 manifest.json 的那一层）
  6. 更新时：下载新版 ZIP 解压覆盖同名文件夹，再点扩展卡片上的刷新按钮即可
适用场景
网页禁止复制的文本
图片中的文字
PDF 预览中的内容
嵌入 iframe 的文字
会议录制中的文字

URL 智能归一化

网页工具

输入任意 URL，自动解析所有参数并智能评分（核心/可选/追踪），生成 4 种归一化方案，iframe 并排预览对比各方案的实际页面效果。支持自定义规则学习、ClearURLs 追踪参数库集成、穷举模式。

✓ 两种分析模式 智能模式（参数≥6，规则库+语义评分） / 穷举模式（参数≤5，N+1方案逐个测试）
✓ 参数智能评分 域名白名单 + 语义分析：核心参数（id/v/q）得分3，追踪参数（utm_*/fbclid）得分0
✓ 4 种归一化方案 删除所有 / 仅核心 / 核心+可选 / 仅删追踪，自动排序推荐
✓ iframe 并排预览 原始 URL 和所有方案在 iframe 网格中并排加载，直观对比哪个方案最优
✓ 规则学习系统 上传原始→归一化配对数据，自动提取域名级/路径级规则，持久化到 localStorage
✓ ClearURLs 集成 在线获取追踪参数黑名单，加载失败自动降级到内置规则
🔗 打开 URL 归一化工具 →
← 点击按钮在新标签页打开（纯网页工具，非书签）
使用流程
  1. 输入 URL：粘贴任意带参数的 URL（如搜索结果、分享链接、追踪链接）
  2. 选择模式：参数多选智能分析，参数少选穷举测试
  3. 查看评分：每个参数标注重要性（核心 / 可选 / 追踪）
  4. 对比预览：iframe 并排展示原始和归一化版本，确认页面正常且 URL 最简洁
  5. 导出规则：确认方案后，可导出规则供下次复用
参数评分机制
得分类别示例参数
3 分核心参数id, v, q, p, pid, aid, cid, token
2 分可选参数lang, locale, t
1 分未知/单字母a, b, x
0 分追踪参数utm_source, utm_medium, fbclid, gclid, ref, spm, trackid
4 种归一化方案
方案 A：删除所有参数
方案 B：仅保留核心参数
方案 C：核心+可选参数
方案 D：仅删除追踪参数
